# Menti Join

A tiny Mac menu bar app that joins the Menti on your screen in one click.

**Download:** [Menti-Join.dmg](https://github.com/svallfors/menti-join-releases/releases/latest/download/Menti-Join.dmg) · **Website:** https://svallfors.github.io/menti-join-releases/

1. Open the DMG and drag **Menti Join** to Applications.
2. Open it. A Menti icon appears in the menu bar.
3. Allow **Screen Recording** and **Automation for Google Chrome** when asked.

When you're in a Google Meet in Chrome and a Menti QR code or join code is on screen, the menu bar item changes to **Join Menti**. Click it to open the voting page. Click the icon any time to scan manually.

Requires macOS 15.5 or later. Signed and notarized by Apple.
